How it works. Max rise = (ATH ÷ ATL − 1) × 100, using CoinGecko all-time high and low in INR. Watch score (0–100) combines market-cap rank (20), liquidity (20), distance from ATH (15), 30-day momentum (15), how little the coin has risen historically (15), 24h price stability (10) and data quality (5). Prices load live from CoinGecko every time the page opens. If CoinGecko is busy, the page shows the saved daily snapshot instead. The "new since" list compares daily snapshots.

Not financial advice. This is a screening and ranking tool. It does not predict prices. Low token price does not mean a coin is cheap; check market cap, supply and the project itself before investing.
